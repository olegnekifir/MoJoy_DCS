# MoJoy DCS 🕹️

**MoJoy DCS** — это утилита для игры *DCS World* на **WINDOWS 11**, которая превращает движения вашей мыши в эмуляцию левого стика геймпада Xbox 360. 

---

## ⚙️ Функционал

1. **Включение / Выключение эмуляции** 
   - По умолчанию назначено на `CapsLock`.
2. **Тонкая настройка чувствительности стика**:
   - `0.0` — Стандартная чувствительность *(Рекомендуемая)*.
   - От `-0.1` до `-10.0` — Пониженная чувствительность.
   - От `0.1` до `10.0` — Повышенная чувствительность.
3. **Центрирование** 
   - Возвращение стика в нулевое положение (по умолчанию `СКМ` — средняя кнопка мыши).
4. **Кастомизация управления** 
   - Возможность переназначения горячих клавиш для пунктов 1 и 3.

---

## ⚠️ ВАЖНО: Особенности и установка
*(Обязательно к прочтению перед использованием!)*

- 🚀 **ЗАПУСК:** Программу необходимо запускать **ДО** запуска DCS World.
- ⌨️ **УПРАВЛЕНИЕ КАБИНОЙ:** В настройках самой игры обязательно оставьте стандартную комбинацию переключения кликабельной кабины — `Alt + C`.
- ⚠️ **ПЕРЕКЛЮЧЕНИЕ:** Переключайтесь между видами с **ВЫКЛЮЧЕННОЙ ЭМУЛЯЦИЕЙ**,
- 🔄 **АВТОМАТИЗАЦИЯ:** При включении и выключении эмуляции программа *автоматически* прожимает `Alt + C`. **Перед включением программы убедитесь, что режим кликабельной кабины в игре выключен.**

## 🛠 Сборка проекта (для разработчиков)

Проект написан на Python (код сгенерировала ИИ, даже этот md файл + добавлены подробные комментарии от ИИ). 
Сборка в `.exe` файл производилась с помощью **Nuitka** следующей командой:

```cmd
python -m nuitka --onefile --windows-console-mode=disable --windows-icon-from-ico=logo.ico --include-data-files="C:\Users\4227~1\AppData\Local\Programs\Python\Python312\Lib\site-packages\vgamepad\win\vigem\client\x64\ViGEmClient.dll=vgamepad/win/vigem/client/x64/ViGEmClient.dll" --include-data-files="C:\MoJoy_DCS\bin\driver.exe=bin/driver.exe" --remove-output "main.py"
```

Измените пожалуйста путь до файла-установщика ViGEmBus "driver.exe" Он у вас будет отличаться и также если не собирается .exe-файл, проверьте где находится файл библиотеки через Консоль (Терминале) данной командой:

```cmd
python -c "import sys; from pathlib import Path; print(*[p for p in [next(Path(sp).rglob('ViGEmClient.dll'), None) for sp in sys.path if Path(sp).is_dir()] if p], sep='\n')
```

Путь на конце должен выглядеть так: *vgamepad\win\vigem\client\x64\ViGEmClient.dll*

И также пишите команду установки в терминале (Консоли) в папке, где находится main.py!
